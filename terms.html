利用規約

Scoring64 を使うときの条件です。インストール・利用をもって、この規約に同意したものとします。

制定日 2026年10月19日

対象

この規約は、株式会社Fermion（以下「販売元」）が提供する Scoring64 のダウンロード版（Windows と Mac）と、Codex・Claude Code 向けの Scoring64 採点プラグインに適用します。

Mac App Store 版と iPad 版には、この規約に加えて、Apple の標準使用許諾契約（Licensed Application End User License Agreement）が適用されます。

Scoring64 の著作権は販売元にあります。

無料で使える範囲

  • パソコン1台ごとに、毎月2テストまで、人数の制限なしで、すべての機能を使えます。
  • 初めて採点するテストを1回と数え、日本時間の毎月1日に無料枠を更新します。同じテストへの答案の追加・再採点・出力では、枠を消費しません。
  • 無料枠を使い切ると、新しいテストの採点だけを停止します。同じテストの続きの採点・訂正・出力、用紙作成、保存済みデータの閲覧・バックアップ・復元は引き続き使えます。

有料版

  • 有料版はテスト数の制限なく使えます。1教室・1契約につき最大5台のパソコンで使え、パソコンごとに専用のライセンスキーを発行します。キーは発行したパソコンでだけ使えます。
  • 料金・支払い方法・サポートの期間は、料金と申し込みに記載したとおりです。
  • 月払い・年払い・保守は自動で更新します。解約は、次の更新日より前に contact@fermion.company へメールでお知らせください。解約の手数料はなく、支払い済みの期間の終わりまで使えます。
  • デジタル製品の性質上、購入後・利用開始後のお客様都合による返品・キャンセルは受け付けません。法令上必要な場合と、販売元の責めに帰すべき事由がある場合を除き、支払い済みの料金の返金や日割りの返金はしません。
  • 有料キーの期限が過ぎると、無料で使える範囲に戻ります。作成済みの試験や採点データは消えません。
  • 有料版の詳しい条件は「Scoring64 ソフトウェア使用許諾契約書」によります。契約書は、ご契約のとき、またはご希望に応じてお送りします。契約書に別の定めがあるときは、契約書を優先します。

禁止すること

  • Scoring64 を再配布・転売・改変すること
  • ライセンスキーを、発行したパソコン以外で使えるようにすること

データの扱い

  • 答案・成績・名簿は、使っているパソコンの中だけで処理し、販売元へ送りません。詳しくはプライバシーポリシーをご覧ください。
  • データはパソコンごとに保存します。バックアップは利用者が取ってください。
  • 採点プラグインを使うと、AI エージェントが読み取った答案の画像・氏名・採点の指示が、利用者が使っている AI サービスに送られることがあります。その扱いは、その AI サービスの規約に従います。

採点結果の確認

自動で読み取った結果や、AI エージェントが付けた点数は、先生が確認してから使ってください。「要確認」とした答案は、答案と見比べてから点数を確定してください。

第三者のソフトウェア

Scoring64 に含まれる第三者のソフトウェアには、それぞれのライセンスが適用されます。ライセンス文は、インストール先の THIRD_PARTY_LICENSES フォルダにあります。

この規約は日本法に準拠します。Scoring64 について紛争が生じたときは、東京地方裁判所を第一審の専属的合意管轄裁判所とします（強行法規が適用される場合を除きます）。
