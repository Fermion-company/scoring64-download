Getting started

From the download to grading the sample exam that comes with the app.

Scoring64 is in English on Windows and Mac from version 1.2.0. The button names on this page are the English ones from 1.2.0.

  • Install
  • First launch
  • Try the sample

Download and install

Use a Windows 10 / 11 computer (Intel or AMD, 64-bit), or a Mac with Apple silicon (M1 or later) and macOS 14 or later. This desktop download does not run on Intel Macs, phones or tablets.

Install on Windows

Windows 10 / 11 (64-bit)

  1. Download the installer (Scoring64-Setup.exe).
  2. Open the file and follow the prompts. You do not need administrator rights.
Download

Install on a Mac

Mac with Apple silicon (M1 or later), macOS 14 or later. Not for Intel Macs.

  1. Download the Mac version (Scoring64-mac-arm64.zip).
  2. Open the zip to get Scoring64.app, and move it to your Applications folder.
  3. Open Scoring64 from Applications. If you cannot copy it there, ask your Mac administrator for help.

A separate edition with in-app purchases is listed on the Japan Mac App Store. It may not be available in your region. The direct download on this page is the edition used by this guide and the AI grading setup.

Updating an older Mac download

Version 1.3.1 is now available for Windows and Mac. Mac downloads through version 1.2.0 need a one-time manual update (1.2.1 updates automatically). If the app cannot find compatible update information, check the latest release. On an Apple silicon Mac with macOS 14 or later, save your work, back up your exams, quit Scoring64, then replace the app in Applications using the Mac ZIP above. Keep your Scoring64 data folder.

Version 1.2.1 and later check the required macOS version before downloading an update. If your Mac is too old for an update, your existing app stays in place.

macOS 13 and earlier are not supported. Keep your existing app and data, and ask your Mac administrator whether you can update macOS. Back up your data before an OS update. We have not verified an older compatible release or data compatibility when downgrading, so we do not recommend downgrading. Contact us for help.

If the Mac cannot open the app

The current direct download is Developer ID signed and notarized by Apple. If you have an older download, download it again using the button above and replace the app in Applications. Keep your Scoring64 data folder.

If macOS says the app is damaged, the developer cannot be verified, or the app is not supported on this Mac, check Apple menu → About This Mac for an Apple M-series chip and macOS 14 or later. If those requirements are met, send us the exact message. You should not need to disable Gatekeeper or remove quarantine attributes.

If you are asked for keychain access after an in-app update

Download or app won't open?
  • The download does not finish: check your browser's Downloads list. Windows needs the complete Scoring64-Setup.exe; Mac needs Scoring64-mac-arm64.zip. A saved web page ending in .html is not the app. You can also find the files under Assets on the release page. If GitHub is blocked on your school network, ask your IT administrator or contact us.
  • The file will not open: use the file for your OS and check the requirements above. Wait for the download to finish, then run the Windows installer or extract the Mac ZIP before opening the app. For Windows warnings, see Install on Windows.
  • The app still fails to start: email contact@fermion.company with your OS and version, the downloaded filename, and the exact error message or a screenshot. On Mac, also include the chip shown in About This Mac. Tell us whether it stops during download, installation or launch.

You can open Scoring64 and try its sample before setting up any AI service or plugin. AI setup is a separate step.

First launch

  1. Scoring64 opens when the installation finishes. After that, open it from the Start menu or the desktop shortcut; on a Mac, from Applications.
  2. On both Windows and Mac, Scoring64 opens in its own window, not in a browser. The first launch can take about 30 seconds. On a Mac, the initial macOS security check can take a few minutes.

Grading and reading answer sheets work offline, entirely on this computer, and stop when you close the window. Scoring64 goes online only to check for new versions and to set up TeX if you design sheets in the app.

Try the sample

The app comes with a sample exam you can grade from start to finish. No paper, scanner or key needed; it takes about five minutes. The sample is a Japanese science quiz, but the steps are the same for your own tests.

  1. Click Try the sample.
  2. Import the sample answer sheets.
  3. Bubble questions are graded automatically. Check the answers sent to Needs review.
  4. Grade the written questions, one student at a time.
  5. On the Export & backup tab, click Make the return ZIP. You get a ZIP with a marked PDF for each student and a scores CSV that opens in Excel.

The ZIP holds every student's paper. When handing back, give each student only their own PDF from the students folder.

Start over resets the sample as often as you like, and the sample exports without a key. To try one of your own tests, start by preparing the sheet.

More about keys and data

Free tests and license keys

Each computer can grade 2 tests a month with every feature and no limit on students. When the free tests are used up, only grading a new test stops: you can still continue, correct and export tests you have started, design sheets, and view, back up and restore your data. The free tests reset on the 1st of each month, Japan time (JST).

To grade more tests, contact us for a paid license. Click the counter at the top right (2 free tests left this month, for example) or License, then click the This computer's code field and copy all of it.

Send the code to contact@fermion.company with your school or center name. When your key (a long string starting with S64-1.) arrives by email:

  1. Click the free-tests counter at the top right.
  2. Copy the whole key from the email and paste it. Line breaks in the middle are fine.
  3. Click Register. Your exams and grading carry on where you left them.

The counter at the top right shows how many free tests are left this month. A paid key removes the limit. Running out of free tests never deletes your exams or grades.

Where your data is kept

Exams, scanned answer sheets and grades are saved in this folder on your computer. They are never sent to an outside server.

%LOCALAPPDATA%\Scoring64\data

The Start menu has a shortcut to the data folder.

On a Mac, they are saved here:

~/Library/Application Support/Scoring64

In Finder, choose Go → Go to Folder and paste this path.

Uninstall

Use the uninstall shortcut in the Start menu, or remove Scoring64 under Windows Settings → Apps.

On a Mac, move Scoring64.app from Applications to the Bin. Your data stays in ~/Library/Application Support/Scoring64.

Uninstalling does not delete the data folder. If you reinstall, you carry on where you left off.

Move to another computer
  1. On the old computer, click Back up all exams on the Export & backup tab. Every exam goes into one file (.scoring64).
  2. Copy that file to the new computer, for example on a USB stick.
  3. Install Scoring64 on the new computer, send us its This computer's code, and register the key we send for that computer.
  4. Click Restore from backup and choose the file.

A paid license covers up to five computers in one classroom. For several sites, contact us for a quote. If a computer's code changes because you replaced the computer or reinstalled the system, contact us as well.
